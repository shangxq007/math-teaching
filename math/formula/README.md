# 速查表

考前最后 10 分钟看的高密度公式表。

## 定位与分工

| 文档 | 内容 | 篇幅 |
| --- | --- | --- |
| 理论概要 `../outline/` | 定义、定理 + 推导 | 每章 1～2 页 |
| **速查表（本目录）** | **只有结果，没有推导** | **每页 6～8 个专题** |
| 结论卡片 `../map/` | 结论 + 适用条件 + 易错点 | 一卡一结论 |

速查表不解释「为什么」，只回答「是什么」。写完一条就问：
**这条如果学生记不住，他能不能在考场上现场推出来？** 能推的就不必收进来。

## 版式

- `extarticle` 8pt + A4 横版 + `multicol` 三栏，栏间细线；
- 每条一个 `fastcard` 盒子（`../common/envs.tex`）；
- `\clearpage` 分页，不要靠栏自动流。

## 编译

```bash
cd formula
latexmk -xelatex -g main
```

## 文件

```
main.tex             导言区（横版、多栏）
chapters/01.tex      代数与函数
chapters/02.tex      三角、几何与概率统计
chapters/README.md
```
