# 讲义

学生用的主材料，文档体系里**最完整**的一档。

## 定位与分工

| 文档 | 读者 | 回答什么 |
| --- | --- | --- |
| 教案 `../lesson/` | 教师 | 怎么教：目标、重难点、过程、板书 |
| **讲义（本目录）** | **学生** | **学什么：概念、推导、例题、练习、小结** |
| 导学案 `../guide/` | 学生 | 做什么：预习填空、探究、检测、作业 |
| 理论概要 `../outline/` | 师生 | 有哪些：只留骨架，无例题 |
| 结论卡片 `../map/` | 学生 | 用什么：一卡一结论，含适用条件与易错点 |

判断标准：**能不能脱离教师自学**。讲义要能，导学案不能（它依赖课堂任务）。

## 结构

每章固定六段，可按需增删，但顺序不变：

1. **引入**——为什么学（一段话，不写「教学目标」）
2. **概念**——`definition` 环境
3. **推导**——`derivation` 环境（左侧竖线绿框）
4. **例题**——`example` + `solution` 成对
5. **易错点**——`commonerror{主题}` 环境（橙色框）
6. **小结与方法**——`summary` + `method` 环境
7. **练习**——`exercise` 环境

## 写法约定

- 推导必须写「为什么这样想」，不能只写计算步骤。
- 例题要有「解」，且解的最后一步要回扣题目结论。
- 易错点写「错法 + 为什么错 + 正确写法」三段，不只写「易错」。
- 每章末尾用 `\reading{编号}{篇名}` 指向 `../extension/` 的对应篇目。
