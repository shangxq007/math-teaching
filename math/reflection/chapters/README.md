# 教学反思章节写法

## 文件命名

`01.tex`、`02.tex`……与 `../lesson/chapters/` 的课次号一致，便于对照看。
新增后在 `../main.tex` 里加 `\input{chapters/02}`。

## 骨架

见 `../README.md`。三段标题固定为「达成情况 / 意外之处 / 下次调整」。

## 与教案的对照

写完反思后，回头在 `../lesson/chapters/NN.tex` 的 `keypoint` 或 `procedure` 里补一句
「第 N 次课的实际反应」，让下一轮备课直接看到上一轮的记录。

## 期末汇总

在 `chapters/99-summary.tex` 里统计：
- 哪个知识点重复出现「意外之处」最多；
- 哪条「下次调整」连续两轮都没被执行。

前者是下学期要重讲的内容，后者是自己的执行问题。
