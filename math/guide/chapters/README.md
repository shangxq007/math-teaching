# 导学案章节目录

每个文件对应**一章**（内容完整，课时划分由教师把握）。文件名以两位序号开头，
按顺序在 `../main.tex` 中 `\input`。

- `01.tex` — 集合与常用逻辑用语（第 1 章）
- `02.tex` — 一元二次函数、方程和不等式（第 2 章）
- `03.tex` — 函数、幂函数、指数函数、对数函数（第 3、4 章）
- `04.tex` — 三角函数（第 5 章）

新增章节步骤：

1. 在此目录新建 `NN.tex`（如 `05.tex`）；
2. 在 `../main.tex` 中追加 `\input{chapters/05}`；
3. 保存即自动编译。

模板使用 ElegantNote（article 结构），章节用 `\section`；章内的内容分节用
`\subsection`，预习用的「知识回顾 / 课前速读」用 `\subsection*`（否则目录会出现
「3.1 3 …」这种双重编号）。
