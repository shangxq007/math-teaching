1. 线性代数特征值（矩阵对角化）：是处理高阶线性常系数递推数列最系统、最机械化的通用引擎（彻底终结一阶、二阶线性递推的配凑技巧）；
2. 发生函数（Generating Functions）：把整个无穷离散数列 \(\{a_n\}\) 打包压缩成一个连续幂级数 \(G(x) = \sum a_n x^n\)，用代数方程求解通项（强基与竞赛核武器）；

下面为你精准定位它们在第 5 章（数列与离散动态系统）中的结构位置、适用边界与实战威力：

一、 线性代数特征值：统一所有线性常系数递推

• 结构本质（状态空间向量演化）：
对于二阶线性递推 \(a_{n+2} = p a_{n+1} + q a_n\)，将其改写为二维状态向量的矩阵乘法：
\(\left(\begin{matrix}a_{n+2}\\ a_{n+1}\end{matrix}\right)=\left(\begin{matrix}p&q\\ 1&0\end{matrix}\right)\left(\begin{matrix}a_{n+1}\\ a_{n}\end{matrix}\right)=A^{n}\left(\begin{matrix}a_{2}\\ a_{1}\end{matrix}\right)\)
求解转移矩阵 \(A\) 的特征多项式 \(\det(\lambda I - A) = \lambda^2 - p\lambda - q = 0\)，特征值 \(\lambda_1, \lambda_2\) 直接决定了通项的基底结构：
	• 若 \(\lambda_1 \neq \lambda_2\)（特征向量张成全空间），通项必为 \(a_n = c_1 \lambda_1^{n-1} + c_2 \lambda_2^{n-1}\)；
	• 若 \(\lambda_1 = \lambda_2\)（重特征值，Jordan 块退化），通项必为 \(a_n = (c_1 + c_2 n)\lambda_1^{n-1}\)。
• 教学价值：特征根法与不动点法在这里实现完美合流（一阶线性递推 \(a_{n+1} = pa_n + q\) 本质上就是特征值为 \(p\) 和 \(1\) 的二阶矩阵特例）。在讲义中作为“通项公式的终极统一模型”，能让学生彻底告别对配凑待定系数的恐惧。

二、 发生函数（Generating Functions）：离散与连续的终极桥梁

• 结构本质（形式幂级数同构）：
在你的“集合与映射”视角下，发生函数建立了离散序列空间 \(\{a_0, a_1, a_2, \dots\}\) 到连续函数空间 \(G(x) = \sum_{n=0}^{\infty} a_n x^n\) 的一一映射。它将序列的“移位递推”转化为幂级数的“乘以 \(x\)”，将“序列卷积”转化为“函数乘积”。
• 核心威力与适用边界：
	• 擅长领域：求解斐波那契数列、卡特兰数（Catalan Number，组合计数压轴常客）及带非齐次项（如 \(a_{n+1} = 2a_n + n\)）的递推通项——只需列出关于 \(G(x)\) 的代数方程，解出有理分式后用等比级数/二项式展开读取 \(x^{n}\) 系数即可。
	• 教学定位：由于涉及形式幂级数展开，极适合作为强基计划、竞赛拓展或“学有余力者探究专栏”放入第 5 章末尾，用来展示“如何用连续函数的代数运算解决离散组合计数”。

三、 Abel 变换（分部求和法）：秒杀“错位相减”的离散微积分神技

• 结构本质（离散乘积求导法则）：
设 \(B_k = \sum_{i=1}^k b_i\)（规定 \(B_0 = 0\)），则有 Abel 恒等式：
\(\sum _{k=1}^{n}a_{k}b_{k}=a_{n}B_{n}-\sum _{k=1}^{n-1}(a_{k+1}-a_{k})B_{k}\)
在你的“离散微积分”体系中，这正是分部积分 \(\int u\,dv = uv - \int v\,du\) 的精确离散版本！
• 高考实战的降维价值（强烈建议全员掌握）：
	• 彻底消灭“错位相减法”的计算失误：高考数列大题每年必考“等差 \(\times \) 等比”求和（如 \(\sum_{k=1}^n (2k-1)\cdot 2^k\)），传统错位相减极易写错项数和符号。套用 Abel 变换公式，只需算一次等比数列前缀和 \(B_{k}\)，差分 \(a_{k+1}-a_k\) 直接变成常数 \(d\)，三行写出绝对零失误的标准答案（阅卷时只需把 Abel 变换的中间展开步骤写出来，完全符合考纲规范）。
	• 数列不等式放缩利器：在压轴题证明 \(\sum_{k=1}^n a_k b_k < M\) 时，若 \(a_{k}\) 单调递减趋近于 0 且部分和 \(B_{k}\) 有界，Abel 变换能瞬间完成精准放缩。
