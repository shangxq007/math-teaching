一、 专题微讲义：《不动点原理：从递归数列到嵌套函数方程》


【核心结构导图】

\(\text{映射迭代 }x_{n+1}=f(x_{n})\xrightarrow{\text{寻找平衡态 }f(x^{*})=x^{*}}\begin{cases}\text{数列视角：构造等比/等差公比基底}\\ \text{函数视角：锁定嵌套方程 }f(f(x))=x\text{ 的核心根集}\\ \text{几何视角：曲线 }y=f(x)\text{ 与直线 }y=x\text{ 的交点}\end{cases}\)

模块一：不动点的几何本质与稳定性判据

1. 定义：对于映射 f: D → D，若存在 \(x^* \in D\) 使得 \(f(x^*) = x^*\)，则称 \(x^{*}\) 为函数 f 的不动点。在笛卡尔坐标系中，不动点集合即函数点集 \(\{(x,y)\mid y=f(x)\}\) 与恒等映射点集 \(\{(x,y)\mid y=x\}\) 的交集横坐标。
2. 动态稳定性判据（巴拿赫压缩映射雏形）：
	• 当 \(\vert{}f'(x^*)\vert{} < 1\) 时，\(x^{*}\) 为吸引不动点（稳定平衡态），邻域内的迭代序列 \(a_{n+1}=f(a_n)\) 沿蛛网图螺旋/阶梯收敛于 \(x^{*}\)；
	• 当 \(\vert{}f'(x^*)\vert{} > 1\) 时，\(x^{*}\) 为排斥不动点（不稳定平衡态），迭代序列将沿蛛网图加速发散逃离 \(x^{*}\)。

模块二：实战武器一 —— 不动点法秒杀三大递推数列


递推类型	不动点特征方程	换元降维构造公式（直接转化）	考纲规范书写建议
1. 一阶线性递推
\(a_{n+1} = pa_n + q\ (p \neq 1)\)	唯一不动点 \(x^* = \frac{q}{1-p}\)	\(a_{n+1} - x^* = p(a_n - x^*)\)
（直接构成公比为 p 的等比数列）	演算纸求出 \(x^{*}\) 后，解答题直接写“由原式变形得 \(a_{n+1}-x^* = p(a_n-x^*)\)”。
2. 分式递推（双不动点）
\(a_{n+1} = \frac{aa_n + b}{ca_n + d}\)	方程 \(x = \frac{ax+b}{cx+d}\) 有两个相异实根 x₁, x₂	\(\frac{a_{n+1} - x_1}{a_{n+1} - x_2} = k \cdot \frac{a_n - x_1}{a_n - x_2}\)
（两式相除，直接化为等比数列）	算出 x₁, x₂ 后，直接作比值 \(\frac{a_{n+1}-x_{1}}{a_{n+1}-x_{2}}\) 代入递推式化简即可。
3. 分式递推（重不动点）
\(a_{n+1} = \frac{aa_n + b}{ca_n + d}\)	方程 \(x = \frac{ax+b}{cx+d}\) 有唯一重根 x₀	\(\frac{1}{a_{n+1} - x_0} - \frac{1}{a_n - x_0} = \text{常数}\)
（减不动点后取倒数，化为等差数列）	算出重根 x₀ 后，直接计算 \(\frac{1}{a_{n+1}-x_0} - \frac{1}{a_n-x_0}\) 得定值。


模块三：实战武器二 —— 嵌套函数方程 f(f(x)) = x 的集合拆解

• 核心定理（不动点遗传性）：设方程 f(x) = x 的解集为 S₁，方程 f(f(x)) = x 的解集为 S₂，则恒有集合包含关系：S₁ ⊆ S₂（因为若 f(x₀)=x₀，则 f(f(x₀))=f(x₀)=x₀）。
• 单调函数重要推论：
	1. 若 f(x) 在定义域上单调递增，则 S₂ = S₁（嵌套方程没有额外新根，\(f(f(x))=x \iff f(x)=x\)，用反证法一秒可证：若 f(x)>x，由单调递增必有 f(f(x))>f(x)>x，矛盾）。
	2. 若 f(x) 非单调或单调递减，则补集 \(S_2 \setminus S_1\) 中的根必然成对出现，构成2-周期轨道 \(\{a, b\}\)，满足 f(a)=b 且 f(b)=a（几何上表现为点 (a,b) 与 (b,a) 关于直线 y=x 对称）。

模块四：精选实战例题与解析

• 【例 1】（分式双不动点） 已知数列 \(\{a_n\}\) 满足 a₁ = 2，\(a_{n+1} = \frac{2a_n + 3}{a_n + 4}\)，求通项公式 \(a_{n}\)。
	• 【不动点预判】：解不动点方程 \(x = \frac{2x+3}{x+4} \Rightarrow x^2 + 2x - 3 = 0\)，得相异不动点 x₁ = 1, x₂ = -3。
	• 【规范落地】：作比值 \(\frac{a_{n+1}-1}{a_{n+1}+3} = \frac{\frac{2a_n+3}{a_n+4}-1}{\frac{2a_n+3}{a_n+4}+3} = \frac{a_n - 1}{5a_n + 15} = \frac{1}{5} \cdot \frac{a_n - 1}{a_n + 3}\)。
	• 【结论】：\(\left\{\frac{a_{n}-1}{a_{n}+3}\right\}\) 是首项为 \(\frac{2-1}{2+3}=\frac{1}{5}\)、公比为 \(\frac{1}{5}\) 的等比数列，故 \(\frac{a_n-1}{a_n+3} = \left(\frac{1}{5}\right)^n\)，解得 \(a_n = \frac{5^n + 3}{5^n - 1}\)。
• 【例 2】（嵌套函数根的个数） 设分段函数 \(f(x) = \begin{cases} x^2 - 2, & x \le 1 \\ \ln x, & x > 1 \end{cases}\)，求方程 f(f(x)) = x 的实数根个数。
	• 【集合拆解】：先求不动点子集 S₁（解 f(x)=x）：
		• 当 x ≤ 1 时，\(x^2 - 2 = x \Rightarrow x = -1\)（x=2 舍去）；
		• 当 x > 1 时，\(\ln x = x\) 无解（由切线不等式 \(\ln x \le x-1 < x\)）。故 \(S_1 = \{-1\}\)。
	• 【寻找补集 \(S_2 \setminus S_1\)（2-周期对称点）】：
		• 设 t = f(x)，原方程等价于联立 \(\begin{cases}t=f(x)\\ x=f(t)\end{cases}\)（x ≠ t），即曲线 y = f(x) 与其反函数图像 x = f(y) 在直线 y=x 两侧的对称交点。
		• 当 x ≤ 1 且 t > 1 时，\(t = x^2 - 2 > 1 \Rightarrow x < -\sqrt{3}\)，代入 \(x = \ln(x^2-2)\)，在 \((-\infty, -\sqrt{3})\) 上左侧单调递减、右侧单调递增，极限对比知存在唯一对称根 x₀（同时对应 t₀ = x₀² - 2 > 1 也为根）。
		• 综上，\(S_2 = \{-1, x_0, t_0\}\)，共 3 个实数根。

二、 同屏对比 Manim 动画完整脚本（压缩收敛 vs 扩张发散）

以下脚本将屏幕分为左右两半，左侧演示压缩映射 f(x) = 0.5x + 2（\(\vert{}f'(x^*)\vert{} = 0.5 < 1\)，蛛网图螺旋阶梯收敛于不动点 (4,4)），右侧同步演示扩张映射 g(x) = 1.6x - 1.2（\(\vert{}g'(x^*)\vert{} = 1.6 > 1\)，蛛网图阶梯发散逃离不动点 (2,2)），视觉对比极其强烈。
请保存为 fixed_point_stability.py 直接运行：
python
from manim import *

class FixedPointStabilityComparison(Scene):
    def construct(self):
        FONT_NAME = "SimHei"

        # 1. 顶部总标题与左右分区标题
        main_title = Text("不动点动力学：压缩映射（收敛） vs 扩张映射（发散）", font=FONT_NAME, font_size=26).to_edge(UP)
        self.play(Write(main_title))

        # 左侧坐标系：压缩映射 f(x) = 0.5x + 2, 不动点 (4, 4), |f'(4)| = 0.5 < 1
        left_axes = Axes(
            x_range=[0, 6, 1],
            y_range=[0, 6, 1],
            x_length=5.2,
            y_length=4.8,
            axis_config={"include_tip": True, "font_size": 18}
        ).to_edge(LEFT, buff=0.6).shift(DOWN * 0.4)

        left_label = MathTex(r"f(x) = 0.5x + 2 \quad (|f'(x^*)| = 0.5 < 1)", font_size=24, color=GREEN).next_to(left_axes, UP, buff=0.2)

        # 右侧坐标系：扩张映射 g(x) = 1.6x - 1.2, 不动点 (2, 2), |g'(2)| = 1.6 > 1
        right_axes = Axes(
            x_range=[0, 6, 1],
            y_range=[0, 6, 1],
            x_length=5.2,
            y_length=4.8,
            axis_config={"include_tip": True, "font_size": 18}
        ).to_edge(RIGHT, buff=0.6).shift(DOWN * 0.4)

        right_label = MathTex(r"g(x) = 1.6x - 1.2 \quad (|g'(x^*)| = 1.6 > 1)", font_size=24, color=RED).next_to(right_axes, UP, buff=0.2)

        self.play(
            Create(left_axes), Write(left_label),
            Create(right_axes), Write(right_label)
        )

        # 2. 绘制函数图像、y=x 对角线及不动点
        # 左侧图像
        f_func = lambda x: 0.5 * x + 2
        left_curve = left_axes.plot(f_func, x_range=[0, 5.8], color=GREEN, stroke_width=3)
        left_diag = left_axes.plot(lambda x: x, x_range=[0, 5.8], color=GRAY, stroke_width=2)
        left_fp = Dot(left_axes.c2p(4, 4), radius=0.08, color=YELLOW)
        left_fp_text = MathTex(r"x^* = 4", font_size=22, color=YELLOW).next_to(left_fp, UL, buff=0.1)

        # 右侧图像
        g_func = lambda x: 1.6 * x - 1.2
        right_curve = right_axes.plot(g_func, x_range=[0.75, 4.5], color=RED, stroke_width=3)
        right_diag = right_axes.plot(lambda x: x, x_range=[0, 5.8], color=GRAY, stroke_width=2)
        right_fp = Dot(right_axes.c2p(2, 2), radius=0.08, color=YELLOW)
        right_fp_text = MathTex(r"x^* = 2", font_size=22, color=YELLOW).next_to(right_fp, UL, buff=0.1)

        self.play(
            Create(left_curve), Create(left_diag), FadeIn(left_fp), Write(left_fp_text),
            Create(right_curve), Create(right_diag), FadeIn(right_fp), Write(right_fp_text)
        )
        self.wait(0.6)

        # 3. 同步执行 5 步蛛网图迭代（Cobweb Iteration）
        # 左侧起点 a_1 = 0.5（远离 4）
        curr_x_left = 0.5
        dot_left = Dot(left_axes.c2p(curr_x_left, 0), radius=0.06, color=BLUE)
        
        # 右侧起点 b_1 = 2.25（极其靠近不动点 2，但依然逃离）
        curr_x_right = 2.25
        dot_right = Dot(right_axes.c2p(curr_x_right, 0), radius=0.06, color=ORANGE)

        self.play(FadeIn(dot_left), FadeIn(dot_right))

        for step in range(5):
            # 左侧下一步计算
            next_y_left = f_func(curr_x_left)
            v_line_l = Line(
                left_axes.c2p(curr_x_left, curr_x_left if step > 0 else 0),
                left_axes.c2p(curr_x_left, next_y_left),
                color=BLUE_B, stroke_width=2.5
            )
            h_line_l = Line(
                left_axes.c2p(curr_x_left, next_y_left),
                left_axes.c2p(next_y_left, next_y_left),
                color=BLUE_B, stroke_width=2.5
            )

            # 右侧下一步计算
            next_y_right = g_func(curr_x_right)
            v_line_r = Line(
                right_axes.c2p(curr_x_right, curr_x_right if step > 0 else 0),
                right_axes.c2p(curr_x_right, next_y_right),
                color=ORANGE, stroke_width=2.5
            )
            h_line_r = Line(
                right_axes.c2p(curr_x_right, next_y_right),
                right_axes.c2p(next_y_right, next_y_right),
                color=ORANGE, stroke_width=2.5
            )

            # 同步绘制垂直撞击函数曲线
            self.play(
                Create(v_line_l),
                dot_left.animate.move_to(left_axes.c2p(curr_x_left, next_y_left)),
                Create(v_line_r),
                dot_right.animate.move_to(right_axes.c2p(curr_x_right, next_y_right)),
                run_time=0.55
            )
            # 同步绘制水平反射到 y=x
            self.play(
                Create(h_line_l),
                dot_left.animate.move_to(left_axes.c2p(next_y_left, next_y_left)),
                Create(h_line_r),
                dot_right.animate.move_to(right_axes.c2p(next_y_right, next_y_right)),
                run_time=0.55
            )

            curr_x_left = next_y_left
            curr_x_right = next_y_right

        # 4. 底部结论对比总结
        left_concl = Text("吸引不动点：台阶越来越小，稳步收敛", font=FONT_NAME, font_size=20, color=GREEN).next_to(left_axes, DOWN, buff=0.25)
        right_concl = Text("排斥不动点：台阶越来越大，加速逃离", font=FONT_NAME, font_size=20, color=RED).next_to(right_axes, DOWN, buff=0.25)

        self.play(Write(left_concl), Write(right_concl))
        self.wait(2.5)
