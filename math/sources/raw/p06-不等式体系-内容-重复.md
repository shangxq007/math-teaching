高中阶段的核心不等式体系由“基本不等式、柯西不等式、三角不等式、切线放缩（超越不等式）及权方和/排序不等式”五大支柱构成，它们在结构上分别对应着“几何平均与算术平均的测度关系、向量内积空间、度量空间三角公理以及凸函数的局部线性化”。
为了契合你注重“底层结构与逻辑连贯”的教学思路，以下按“底层来历（结构本质）→ 核心证明方法 → 实战使用口诀与配凑技巧 → 高考考察题型”四个维度进行系统梳理：

一、 高中五大核心不等式全景结构表

二、 使用方法与核心配凑技巧（“一正、二定、三相等”的深层操作）

在实战中，学生最大痛点不是背不出公式，而是变形配凑找不到方向。按代数结构可分为四大标准动作：
1. “1”的代换（齐次化思想）：
	• 特征：已知线性条件 ma + nb = k，求分式 \(\frac{p}{a} + \frac{q}{b}\) 的最值（一次式与负一次式相乘得零次齐次式）。
	• 操作：将目标式乘以 \(\frac{ma+nb}{k}\)，展开后利用基本不等式；更快的降维方法：直接对分式使用权方和不等式，秒出结果。
2. 消元与因式分解（主元法 / 换元法）：
	• 特征：双变量等式（如 x + 2y + xy = 30），求 xy 或 x+2y 的最值。
	• 操作：① 直接对等式用基本不等式把 x+2y 放缩为 \(2\sqrt{2xy}\)，转化为关于 \(\sqrt{xy}\) 的一元二次不等式；② 或解出 \(y = \frac{30-x}{x+2}\)，转化为单变量函数（对勾函数）求最值。
3. 拆项与添项（凑定值结构）：
	• 特征：分母含多项式，如求 \(f(x) = \frac{x^2 + 3x + 5}{x + 1}\ (x > -1)\) 的最小值。
	• 操作：设 t = x + 1 > 0，将分子用 t 表示（降幂分离常数），凑出对勾函数 \(t + \frac{k}{t} + c\)。
4. 切线放缩消超越（导数压轴题核心）：
	• 特征：证明含 \(e^{x}\)、\(\ln x\) 与多项式混合的不等式恒成立（如 \(e^x - \ln x > 2\)）。
	• 操作：用 \(e^x \ge x + 1\) 和 \(-\ln x \ge 1 - x\) 分别在切点 x=0 与 x=1 处局部线性化，相加直接消去超越函数（注意验证两个等号能否同时取到，若不能同时取等，不等号直接变为严格大于 >）。

三、 高考常见考察方式与经典题型分布

高考对不等式的考察早已脱离单纯的公式套用，而是深度嵌入函数、数列、解析几何与导数四大板块中：
• 题型 1：选填小题中的“双变量条件最值”（高频）
	• 考察方式：给出 a,b>0 满足某个代数或指对等式（如 \(2^a + 2^b = 4\) 或 \(\frac{1}{a} + \frac{2}{b} = 1\)），求复杂分式或乘积的最值。
	• 核心陷阱：多步连续放缩导致等号条件冲突（上一步取等要求 a=b，下一步取等要求 a=2b，最终导致求出的最值根本取不到）。
• 题型 2：一元二次不等式与“含参分类讨论”（基础必考）
	• 考察方式：解含参数 a 的不等式 ax² - (a+1)x + 1 < 0，或已知不等式解集反求参数（韦达定理端点对应）。
	• 集合视角本质：考察二次函数点集在 x 轴下方的区间结构，按“二次项系数正负零 → 判别式 Δ 符号 → 两根大小比较”三层树状结构分类。
• 题型 3：恒成立与能成立问题（函数与导数核心）
	• 考察方式：∀ x ∈ D, f(x) ≥ a（转化为 \(f(x)_{\min} \ge a\)）或 ∃ x ∈ D, f(x) ≥ a（转化为 \(f(x)_{\max} \ge a\)）；双变量任意与存在混合（如 \(\forall x_1, \exists x_2, f(x_1) \ge g(x_2) \iff f_{\min} \ge g_{\min}\)）。
• 题型 4：解析几何中的“面积/弦长最值”（综合应用）
	• 考察方式：在椭圆或抛物线中，用韦达定理把三角形面积 S 或弦长 |AB| 表示成斜率 k 的分式函数（如 \(S = \frac{\sqrt{k^2+1}}{2k^2+1}\)），随后换元 \(t = \sqrt{k^2+1} \ge 1\)，用基本不等式或函数单调性求最值（注意检验 t 的取值范围能否触及基本不等式的取等点）。
• 题型 5：数列与导数压轴题中的“放缩证明”（拔高选拔）
	• 考察方式：数列求和证明 \(\sum_{i=1}^n a_i < C\)（裂项放缩、等比放缩），或导数中利用切线不等式证明 f(x) > 0。
