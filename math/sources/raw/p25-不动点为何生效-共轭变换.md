不动点法之所以能瞬间化简递推数列，根本原因不在于“真的假设相邻两项相等”（\(a_{n+1}\) 和 \(a_{n}\) 并不相等），而在于我们借用了“坐标平移/分式线性变换（共轭变换）”的代数技巧，把原数列变成了一个以不动点为“原点/基准点”的新数列，从而彻底消去了递推公式中的常数项或分母耦合项。
在你的“集合与映射结构”视角下，这被称为映射的共轭标准型（Conjugacy）。下面用最直观的代数与几何语言拆解它的底层生效机制：

一、 破除误区：并不是“假设 \(a_{n+1} = a_n\)”，而是“解出让常数项归零的偏移量”

以最基础的一阶线性递推 \(a_{n+1} = p a_n + q\) 为例：
为什么我们求不出来它的通项？全怪那个讨厌的常数尾巴 \(+q\)！ 如果没有 \(+q\)，式子就是 \(a_{n+1} = p a_n\)，一眼就能看出是公比为 \(p\) 的等比数列。
1. 寻找“零点偏移量” \(x^{*}\)：
我们想找一个神奇的常数 \(x^{*}\)，把原数列的每一项都减去 \(x^{*}\)，构造新数列 \(b_n = a_n - x^*\)，希望新数列满足纯粹的等比关系：
\(a_{n+1}-x^{*}=p(a_{n}-x^{*})\)
2. 对比系数，不动点方程自然浮现：
把上面目标式子展开移项：
\(a_{n+1}=pa_{n}+(x^{*}-px^{*})\)
拿它和原题给的 \(a_{n+1} = p a_n + q\) 一对比，只要让常数尾巴相等即可：
\(x^{*}-px^{*}=q\iff x^{*}=px^{*}+q\)
看！这个方程在形式上恰好等于把原递推式中的 \(a_{n+1}\) 和 \(a_{n}\) 都替换成 \(x^{*}\)！
3. 生效本质：
	• 所以，“令 \(a_{n+1} = a_n = x^*\)”只是一个方便记忆的快捷操作口诀；
	• 它的真实代数动作是“两式相减消去常数项 \(q\)”：
\(\begin{cases}a_{n+1}=pa_{n}+q\\ x^{*}=px^{*}+q\end{cases}\xrightarrow{\text{上下相减}}a_{n+1}-x^{*}=p(a_{n}-x^{*})\)
	• 几何意义：把数轴的原点从 \(0\) 平移到不动点 \(x^{*}\) 处。在新坐标系下，每迭代一次，点到原点的距离就严格缩放 \(p\) 倍，繁杂的“拉伸+平移”复合变换就还原成了纯粹的“中心缩放”。

二、 分式递推 \(a_{n+1} = \frac{a a_n + b}{c a_n + d}\) 为什么相减作比也能生效？

分式递推（莫比乌斯变换）之所以难，是因为分子分母里同时含有 \(a_{n}\)。不动点法在这里同样是在做“减去不动点以提取公因式 \((a_n - x^*)\)”：
1. 核心代数恒等式（提取因式魔法）：
设 \(x_{1}\) 是不动点（满足 \(x_1 = \frac{a x_1 + b}{c x_1 + d}\)），我们用 \(a_{n+1}\) 直接减去 \(x_{1}\) 并通分：
\(a_{n+1}-x_{1}=\frac{aa_{n}+b}{ca_{n}+d}-\frac{ax_{1}+b}{cx_{1}+d}=\frac{(ad-bc)(a_{n}-x_{1})}{(ca_{n}+d)(cx_{1}+d)}\)
注意看分子！ 因为 \(x_{1}\) 满足不动点方程，通分后的分子一定会把常数项全部抵消，必然可以提取出公因式 \((a_n - x_1)\)！
2. 双不动点作比（消去讨厌的分母 \((c a_n + d)\)）：
	• 虽然分子提取出了 \((a_n - x_1)\)，但分母里还留着一个随 \(n\) 变化的 \((c a_n + d)\)，所以单个式子还不是等比数列。
	• 如果方程还有第二个不同的不动点 \(x_{2}\)，同理可得：
\(a_{n+1}-x_{2}=\frac{(ad-bc)(a_{n}-x_{2})}{(ca_{n}+d)(cx_{2}+d)}\)
	• 两式一除，分母 \((c a_n + d)\) 瞬间上下约掉！
\(\frac{a_{n+1}-x_{1}}{a_{n+1}-x_{2}}=\left(\frac{cx_{2}+d}{cx_{1}+d}\right)\cdot \frac{a_{n}-x_{1}}{a_{n}-x_{2}}\)
右边的括号里全是常数，这就变成了纯粹的等比数列！
3. 重不动点取倒数（把非线性分式变成线性等差）：
	• 如果只有一个重不动点 \(x_{0}\)，没有第二个式子可除怎么办？我们直接把 \(a_{n+1} - x_0\) 取倒数，把分母 \((c a_n + d)\) 翻到分子上去拆项：
\(\frac{1}{a_{n+1}-x_{0}}=\frac{(ca_{n}+d)(cx_{0}+d)}{(ad-bc)(a_{n}-x_{0})}\)
把分子的 \((c a_n + d)\) 写成 \(c(a_n - x_0) + (c x_0 + d)\)，拆成两项，立刻变成：
\(\frac{1}{a_{n+1}-x_{0}}=\frac{c(cx_{0}+d)}{ad-bc}+\frac{(cx_{0}+d)^{2}}{ad-bc}\cdot \frac{1}{a_{n}-x_{0}}\)
而在重根条件下，系数 \(\frac{(cx_{0}+d)^{2}}{ad-bc}\) 恰好恒等于 \(1\)，于是它就化成了最简单的等差数列！

三、 总结与课堂向学生解释的“一句话金句”

在向学生讲授时，可以用这样一句话点破天机，既消除神秘感，又建立极高的数学审美：
“我们不是假设 \(a_{n+1}\) 真的等于 \(a_{n}\)，而是先解出那个‘永远不会动’的平衡点 \(x^{*}\)，然后用每一项去减去 \(x^{*}\)（测量每一项距离平衡点的偏差）。因为平衡点自己不动，两者一减，所有讨厌的常数尾巴就会自动抵消，剩下的‘偏差’就变成了最纯粹的等比缩放！”
