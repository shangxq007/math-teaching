\section*{深度揭秘：为什么“令 $a_{n+1}=a_n=x^*$”能秒杀递推数列？}

\begin{remark}[破除认知误区]
使用不动点法时，我们\textbf{并不是}真的假设相邻两项相等（$a_{n+1}$ 与 $a_n$ 并不相等），而是借用了高等数学中\textbf{“共轭变换（换坐标系）”}的思想：以永远不动的平衡点 $x^*$ 为新的“原点”，测量每一项距离平衡点的\textbf{偏差}，从而利用平衡点自身的不变性，将递推式中的常数项或耦合分母彻底抵消。
\end{remark}

\subsection*{1. 一阶线性递推 $a_{n+1} = pa_n + q$：平移原点消除常数尾巴}
原递推式之所以难以直接写出通项，全在于末尾的常数项 $+q$（每一步既有“拉伸 $p$ 倍”，又有“平移 $q$ 单位”）。
\begin{itemize}
    \item \textbf{第一步（锁定平衡锚点）}：寻找一个特殊点 $x^*$，使得它经过一次变换后仍在原地，即满足方程：
    $$x^* = px^* + q$$
    \item \textbf{第二步（作差测量偏差）}：用原递推式减去平衡点方程，常数项 $q$ 自动抵消：
    $$\begin{cases} a_{n+1} = pa_n + q \\ x^* = px^* + q \end{cases} \xrightarrow{\text{两式相减}} a_{n+1} - x^* = p(a_n - x^*)$$
    \item \textbf{几何本质}：设偏差数列 $b_n = a_n - x^*$，相当于把数轴的坐标原点从 $0$ 平移到了 $x^*$。在新坐标系下，复杂的“拉伸+平移”复合运动退化成了纯粹的\textbf{中心等比缩放} $b_{n+1} = pb_n$。
\end{itemize}

\subsection*{2. 分式递推 $a_{n+1} = \frac{aa_n + b}{ca_n + d}$：提取公因式与消去变分母}
设 $x_1$ 为不动点方程 $x = \frac{ax+b}{cx+d}$ 的一个根，直接计算偏差 $a_{n+1} - x_1$ 并通分：
$$a_{n+1} - x_1 = \frac{aa_n + b}{ca_n + d} - \frac{ax_1 + b}{cx_1 + d} = \frac{(ad-bc)(a_n - x_1)}{(ca_n + d)(cx_1 + d)}$$
\begin{itemize}
    \item \textbf{魔法 1（分子提取公因式）}：正因为 $x_1$ 满足不动点方程，通分后的分子必然把常数项全部抵消，严格提取出因式 $(a_n - x_1)$。
    \item \textbf{魔法 2（双根作比消分母）}：若存在第二个相异不动点 $x_2$，同理写出 $a_{n+1} - x_2$ 的表达式。两式相除，随 $n$ 变化的讨厌分母 $(ca_n+d)$ 瞬间上下约尽：
    $$\frac{a_{n+1} - x_1}{a_{n+1} - x_2} = \left(\frac{cx_2 + d}{cx_1 + d}\right) \cdot \frac{a_n - x_1}{a_n - x_2} \quad (\text{纯粹等比数列})$$
    \item \textbf{魔法 3（重根取倒变等差）}：若仅有唯一重根 $x_0$，则直接取倒数将分母翻到分子拆项：
    $$\frac{1}{a_{n+1} - x_0} = \frac{(ca_n+d)(cx_0+d)}{(ad-bc)(a_n - x_0)} = \frac{c(cx_0+d)}{ad-bc} + \underbrace{\frac{(cx_0+d)^2}{ad-bc}}_{\text{重根时恒为 } 1} \cdot \frac{1}{a_n - x_0}$$
\end{itemize}
Use code with caution.

二、 配套 Manim 动画完整脚本：数轴坐标平移与偏差收缩

这段动画（FixedPointCoordinateShift）采用上下双数轴对比：
• 上数轴（原坐标系）：点 \(a_{n}\) 每次先乘 \(0.5\) 再加 \(2\)，显得杂乱且没有明显的等比规律；
• 下数轴（以不动点 \(x^{*}=4\) 为新原点的共轭坐标系）：直观展示把原点平移到 \(4\) 之后，所有的偏差向量 \(b_n = a_n - 4\) 每一步都严格缩短为原来的一半，让“作差消去常数项”肉眼可见。
请保存为 fixed_point_shift.py 运行：
python
from manim import *

class FixedPointCoordinateShift(Scene):
    def construct(self):
        FONT_NAME = "SimHei"

        # 1. 标题
        title = Text("不动点生效的几何本质：平移原点，将复合运动还原为纯粹缩放", font=FONT_NAME, font_size=24).to_edge(UP)
        self.play(Write(title))

        # 2. 上方数轴：原坐标系（原点在 0，不动点在 4）
        top_nl = NumberLine(
            x_range=[-1, 6, 1],
            length=10,
            include_numbers=True,
            font_size=20
        ).shift(UP * 1.4)
        top_label = MathTex(r"\text{原坐标系: } a_{n+1} = 0.5a_n + 2", font_size=24, color=BLUE).next_to(top_nl, UP, buff=0.25)

        # 下方数轴：共轭坐标系（原点平移至不动点 x* = 4）
        bot_nl = NumberLine(
            x_range=[-5, 2, 1],
            length=10,
            include_numbers=True,
            font_size=20
        ).shift(DOWN * 1.4)
        bot_label = MathTex(r"\text{新坐标系 (} b_n = a_n - 4 \text{): } b_{n+1} = 0.5b_n \text{ (纯粹等比缩放)}", font_size=24, color=GREEN).next_to(bot_nl, UP, buff=0.25)

        self.play(Create(top_nl), Write(top_label), Create(bot_nl), Write(bot_label))

        # 3. 标记不动点 x* = 4 与新原点 0 的垂直对齐虚线
        fp_dot_top = Dot(top_nl.n2p(4), radius=0.09, color=YELLOW)
        fp_text_top = MathTex(r"x^* = 4 \text{ (不动点)}", font_size=22, color=YELLOW).next_to(fp_dot_top, DOWN, buff=0.2)

        fp_dot_bot = Dot(bot_nl.n2p(0), radius=0.09, color=YELLOW)
        fp_text_bot = MathTex(r"\text{新原点 } 0", font_size=22, color=YELLOW).next_to(fp_dot_bot, DOWN, buff=0.2)

        align_line = DashedLine(top_nl.n2p(4), bot_nl.n2p(0), color=YELLOW, stroke_width=2)

        self.play(
            FadeIn(fp_dot_top), Write(fp_text_top),
            FadeIn(fp_dot_bot), Write(fp_text_bot),
            Create(align_line)
        )
        self.wait(0.8)

        # 4. 演示初始点 a_1 = 0 (对应偏差 b_1 = -4) 连续迭代 4 步
        a_val = 0.0
        dot_top = Dot(top_nl.n2p(a_val), radius=0.08, color=BLUE)
        dot_bot = Dot(bot_nl.n2p(a_val - 4), radius=0.08, color=GREEN)

        # 绘制偏差线段（从点到不动点的距离）
        brace_bot = always_redraw(lambda: Line(
            bot_nl.n2p(dot_bot.get_center()[0] / (10/7) + 1 if False else 0), # 占位避免直接读屏幕坐标误差
            bot_nl.n2p(0),
            color=GREEN, stroke_width=5
        ))
        # 更稳妥的动态偏差高亮线
        dev_line = Line(bot_nl.n2p(a_val - 4), bot_nl.n2p(0), color=GREEN, stroke_width=5)
        dev_text = MathTex(r"b_1 = -4", font_size=22, color=GREEN).next_to(dev_line, UP, buff=0.15)

        self.play(FadeIn(dot_top), FadeIn(dot_bot), Create(dev_line), Write(dev_text))
        self.wait(0.8)

        for step in range(1, 5):
            next_a = 0.5 * a_val + 2
            next_b = next_a - 4

            new_dev_line = Line(bot_nl.n2p(next_b), bot_nl.n2p(0), color=GREEN, stroke_width=5)
            new_dev_text = MathTex(rf"b_{{{step+1}}} = {next_b:g} = \frac{{1}}{{2}}b_{{{step}}}", font_size=22, color=GREEN).next_to(new_dev_line, UP, buff=0.15)

            self.play(
                dot_top.animate.move_to(top_nl.n2p(next_a)),
                dot_bot.animate.move_to(bot_nl.n2p(next_b)),
                Transform(dev_line, new_dev_line),
                Transform(dev_text, new_dev_text),
                run_time=1.0
            )
            a_val = next_a
            self.wait(0.4)

        concl = Text("作差减去不动点 = 把坐标原点搬到不动点，所有复杂偏移瞬间归零！", font=FONT_NAME, font_size=22, color=YELLOW).to_edge(DOWN, buff=0.35)
        self.play(Write(concl))
        self.wait(2.5)

三、 深度拓展：共轭变换、莫比乌斯变换，以及数学中的五大核心“降维变换”

你敏锐地捕捉到了现代数学最核心的方法论——Transform-Solve-Inverse Transform（变换—求解—逆变换）。几乎所有看似无解的复杂问题，本质上都是在当前“坐标系/表现形式”下太扭曲，只要换一个视角（施加某种变换），它就会瞬间变成最简单的标准模型。

1. 什么是共轭变换（Conjugacy）？—— “换把尺子看运动”

• 核心公式：\(g = h^{-1} \circ f \circ h\)（在矩阵里就是相似对角化 \(B = P^{-1} A P\)）。
• 通俗类比：你手里有一个歪斜的椭圆，直接算它的面积很麻烦。你先用变换 \(h\)（把坐标系斜着拉伸）把它变成一个标准圆，在圆的世界里（\(g\)）轻松算出面积，再用逆变换 \(h^{-1}\) 还原回来。
• 不动点法就是最纯粹的共轭变换：原递推 \(f(x) = px + q\) 很麻烦，我们通过坐标平移 \(h(x) = x - x^*\)，把它变成了纯粹的等比缩放 \(g(y) = py\)，算完通项 \(y_n = p^{n-1}y_1\) 后，再通过 \(h^{-1}(y) = y + x^*\) 还原出 \(a_{n}\)。

2. 什么是莫比乌斯变换（Möbius Transformation）？—— “分式递推与复平面的统一”

• 核心形式：\(f(z) = \frac{az + b}{cz + d}\ (ad - bc \neq 0)\)，在实数域就是高中分式递推数列，在复数域则是把圆和直线映成圆和直线的保角变换。
• 惊人的矩阵同构性质：莫比乌斯变换的复合运算，与 \(2 \times 2\) 矩阵的乘法完全同构！
	• 求分式递推 \(a_{n+1} = \frac{aa_n + b}{ca_n + d}\) 的第 \(n\) 项，本质上就是算矩阵 \(\left(\begin{matrix}a&b\\ c&d\end{matrix}\right)^{n}\)，而矩阵特征方程 \(\lambda^2 - (a+d)\lambda + (ad-bc) = 0\) 经过简单代换，与分式不动点方程 \(cx^2 + (d-a)x - b = 0\) 拥有完全相同的判别式 \(\Delta = (a-d)^2 + 4bc\)！这就是为什么双不动点对应等比数列（两个相异特征值），重不动点对应等差数列（重特征值的 Jordan 块）。

3. 整个高中与高等数学中最常用的“五大降维变换”全景表

除了共轭变换和莫比乌斯变换，以下五大变换是贯穿高中压轴题与高等数学的通用武器：

变换名称	核心操作公式 / 规则	化繁为简的魔法（把什么变成了什么？）	高中实战对应场景
1. 对数变换
（指数 \(\rightarrow \) 线性）	\(y = \ln x\)	把乘法变成加法、把幂次变成系数、把指数增长变成直线。	指数型递推 \(a_{n+1} = c \cdot a_n^p\) 两边取对数秒变线性递推；非线性回归拟合。
2. 仿射变换
（椭圆 \(\rightarrow \) 圆）	\(x' = x, \ y' = \frac{a}{b}y\)	把椭圆压缩成标准圆，保持共线、平行、中点与面积比例不变。	圆锥曲线内接三角形面积最值、斜率乘积为定值问题秒杀。
3. 齐次化与齐次坐标
（非齐次 \(\rightarrow \) 齐次）	乘以 \(1 = mx+ny\) 或平移原点构造 \(Ax^2+Bxy+Cy^2=0\)	把杂乱的多项式变成每一项次数完全相同的结构，从而可以同除 \(x^{2}\) 转化为单变量斜率 \(k = \frac{y}{x}\)。	基本不等式“1的代换”、圆锥曲线定点定值斜率之和/积问题。
4. 欧拉/复数变换
（三角 \(\rightarrow \) 指数）	\(e^{i\theta} = \cos\theta + i\sin\theta\)	把繁杂的三角函数恒等变形转化为初中生都会的多项式乘法与等比数列。	和差倍半角公式推导、三角数列求和 \(\sum \cos(k\theta)\)。
5. 发生函数/拉普拉斯变换
（递推/微分 \(\rightarrow \) 代数）	\(G(x) = \sum_{n=0}^\infty a_n x^n\)	把无穷数列递推（或微积分导数方程）打包成一个普通函数，转化为解初等代数方程。	斐波那契、卡特兰数及复杂非齐次递推通项求解。
