# Core Pedagogical Logic (核心教学逻辑主线)
必须打破传统“死记公式+盲目凑项”的模式，以**“几何与代数边界约束”**为核心视角，将高中五大核心不等式串联成一个有机整体：

1. **模块一：全景图谱 —— 五大不等式的“几何与结构来历”**
   - 用对比表格与启发式推导讲清来历与证明：
     * **基本不等式** $\frac{a+b}{2} \ge \sqrt{ab}\ (a,b>0)$：揭示其“等周测度原理”与**半圆射影定理几何模型**（直径 $a+b$ 的半径 $\frac{a+b}{2}$ 永远大于等于斜边上的高 $\sqrt{ab}$）及赵爽弦图证明。
     * **柯西不等式** $(a_1^2+a_2^2)(b_1^2+b_2^2) \ge (a_1b_1+a_2b_2)^2$：揭示其**欧氏空间向量内积公理** $|\vec{u}|^2|\vec{v}|^2 \ge (\vec{u}\cdot\vec{v})^2$（取等条件即向量共线），并给出构造二次函数的判别式证法。
     * **权方和不等式** $\frac{a_1^2}{b_1} + \frac{a_2^2}{b_2} \ge \frac{(a_1+a_2)^2}{b_1+b_2}\ (b_1,b_2>0)$：揭示它是柯西不等式的分式齐次化变形，专治“分母相加求最值”。
     * **绝对值三角不等式** $||a|-|b|| \le |a\pm b| \le |a|+|b|$：揭示其**度量空间距离公理（向量三角形法则）**。
     * **切线放缩（超越不等式）** $e^x \ge x+1$ 与 $\ln x \le x-1$：揭示其**凸函数/凹函数的局部线性化（切线支撑边界）**本质，并用导数构造差值函数严格证明。

2. **模块二：操作法则 —— 条件最值配凑的“四大标准动作”与取等陷阱**
   - 深度剖析“一正、二定、三相等”的底层逻辑，系统归纳四类结构化变形技巧：
     1. **齐次化与“1”的代换**（对比普通展开法与权方和不等式秒杀法）；
     2. **消元与主元转化**（双变量等式降维为单变量对勾函数 $t + \frac{k}{t}$）；
     3. **拆项分离常数**（处理分式多项式最值）；
     4. **切线放缩消去超越函数**（重点强调**“多步放缩等号是否同时成立”**的验证技巧）。
   - **专设【易错诊断室】**：通过典型反例（如连续两次使用基本不等式导致取等条件冲突、换元后忽略新元定义域导致无法触及取等点），训练学生的边界检验意识。

3. **模块三：大一统视角下的“含参不等式与恒成立/能成立”**
   - 用**点集上下位置关系**与**集合包含关系**统一解释：

     * 双变量量词问题（$\forall x_1, \exists x_2, f(x_1) \ge g(x_2) \iff f_{\min} \ge g_{\min}$）的集合值域边界本质。

4. **模块四：分层随堂与课后训练（含双视角解析）**

# Role

# Animation Scenes Specification (分场景动画需求)

## Scene 1: `AMGMGeometricProof`（基本不等式的半圆几何模型与动态取等演示）
请设计一个约 45 秒的流畅几何动画：
1. **第一幕（构建半圆与分段直径）**：在屏幕中央绘制一条水平直径 $AB$，用不同颜色（如蓝色与橙色）将其分为左段 $AC = a$ 和右段 $CB = b$，以 $AB$ 为直径向上绘制半圆（圆心为 $O$）。
2. **第二幕（引出算术平均与几何平均）**：
   - 从圆心 $O$ 向上作半径 $OD$，标注长度公式：$\text{半径 } R = \frac{a+b}{2}$（算术平均，黄色高亮）。
   - 从分界点 $C$ 向上作垂线交半圆于点 $P$，连接 $PA, PB$ 构成直角三角形 $\triangle APB$，由射影定理动态推导出垂线段长度：$PC = \sqrt{ab}$（几何平均，绿色高亮）。
3. **第三幕（动态滑动验证不等式与临界取等）**：
   - 使用 `ValueTracker` 让分界点 $C$ 沿着直径 $AB$ 从左向右平滑滑动（同时 $a, b$ 的数值实时动态更新）。
   - 画面右侧同步显示实时大小对比面板：$\frac{a+b}{2}$ 保持不变（固定半径），而绿色垂线段 $PC = \sqrt{ab}$ 始终矮于圆顶。
   - **高潮定格**：当点 $C$ 恰好滑过圆心 $O$（即 $a = b$）的瞬间，绿色垂线段 $PC$ 与黄色半径 $OD$ 完全重合，屏幕闪烁高亮并弹出结论：**“当且仅当 $a = b$ 时，$\sqrt{ab} = \frac{a+b}{2}$（等号成立）”**。

## Scene 2: `TangentInequalityVisualization`（凸函数切线放缩：$e^x \ge x+1$ 与 $\ln x \le x-1$）
请设计一个约 40 秒的函数边界可视化动画：
1. **第一幕（指数切线支撑下界）**：
   - 建立坐标系，绘制指数函数 $y = e^x$（绿色光滑曲线）。
   - 在点 $(0, 1)$ 处切入一条动态旋转的直线，最终精准贴合为切线 $y = x + 1$（橙色直线）。
   - 用半透明垂直填充带（`axes.get_area`）标出 $y = e^x$ 与 $y = x+1$ 之间的差值区域，直观展示整条曲线始终“悬浮”在切线之上，仅在 $x=0$ 处唯一接触，写出 $e^x \ge x + 1$（当且仅当 $x=0$ 取等）。
2. **第二幕（对称翻转得到对数切线上界）**：
   - 画出虚线对称轴 $y = x$，将 $y = e^x$ 与切线 $y = x + 1$ 沿 $y=x$ 对称映射，自然演变为对数函数 $y = \ln x$（蓝色曲线）及其在 $(1, 0)$ 处的切线 $y = x - 1$（红色直线），直观呈现凹函数恒在切线下方：$\ln x \le x - 1$（当且仅当 $x=1$ 取等）。
