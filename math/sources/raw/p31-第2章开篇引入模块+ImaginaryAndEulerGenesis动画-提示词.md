# Core Pedagogical Logic (核心教学逻辑主线)
必须打破传统教材“先硬塞虚数单位 $i=\sqrt{-1}$、再孤立背诵三角公式”的割裂感，以**“几何变换与结构同构”**为唯一主线，实现从虚数 $i$ 到欧拉公式 $e^{i\theta}$ 的自然涌现：

1. **第一幕：数系扩张的几何动力学 —— 为什么需要虚数单位 $i$？**
   - **一维实数轴的局限**：在实数轴上，乘以正数是“纯缩放”，乘以 $-1$ 是“绕原点逆时针旋转 $180^\circ$（掉头）”（连续乘两次 $-1$ 旋转 $360^\circ$ 回到原位）。
   - **空间维度跃迁（$90^\circ$ 旋转算子）**：提出核心问题——是否存在一种“操作算子 $i$”，连续执行两次恰好等于乘以 $-1$（即一次只逆时针旋转 $90^\circ$）？从而自然引出 $i^2 = -1$。一维数轴因无法容纳“横向转弯”而垂直张开虚轴，正式跃升为**二维复平面**。
   - **代数闭包历史彩蛋（卡丹公式悖论）**：简述 16 世纪邦贝利解三次方程 $x^3 = 15x + 4$ 时，如何借用 $\sqrt{-121} = 11i$ 搭建“水下桥墩”，最终虚部抵消还原出真实实数解 $x = (2+i)+(2-i) = 4$，阐明复数作为代数闭包（代数基本定理）的必要性。

2. **第二幕：结构同构发现 —— 为什么单位圆旋转必然是指数函数？**
   - 用单位复数 $z(\theta) = \cos\theta + i\sin\theta$ 表示单位圆上的点，引导学生验证乘法规律：$z(\alpha) \cdot z(\beta) = z(\alpha + \beta)$（**角度相加 $\to$ 复数相乘**）。
   - 唤醒第一章旧知：凡是满足“加法变乘法”结构公理且 $z(0)=1$ 的连续函数，本质上必为指数函数。

3. **第三幕：局部切线速度锁定底数 —— 欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$ 的自然诞生**
   - **对比实指数与复指数的动力学差异**：
     * 实指数 $e^{1\cdot x}$：在 $x=0$ 处切线速度方向为 $+1$（与位置向量**同向推进**，沿实轴走出一维直线爆炸）；
     * 复指数 $e^{i\cdot \theta}$：在 $\theta=0$ 处位置为 $1$，沿单位圆出发的切线速度方向垂直向上，恰好为 $+i$（速度方向始终与位置向量**垂直**，只转弯不伸长，走出二维单位圆）。
   - 对比 $(e^{k\theta})'|_{\theta=0} = k$，唯一锁定系数 $k = i$，水到渠成写出欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$，并代入 $\theta = \pi$ 见证“上帝公式” $e^{i\pi} + 1 = 0$。

4. **第四幕：配套开篇随堂探究题（3道精选概念辨析与计算题）**
   - 包含：① 复平面向量乘以 $i, -i, 1+i$ 的几何旋转与伸缩计算；② 实指数与虚指数切线速度向量对比填空；③ 利用 $e^{i\theta}$ 现场一步推导二倍角公式。

# Role
你是一位精通 Python 与 **Manim Community Edition (manim v0.18+)** 的数学可视化工程师，擅长通过连贯的几何动力学动画揭示抽象代数符号的几何起源。

# Task
请为我编写一套完整的 Manim 动画脚本（`ImaginaryAndEulerGenesis`），用约 60 秒连贯演示**“一维数轴乘 $-1$ 转 $180^\circ$ $\to$ 乘 $i$ 转 $90^\circ$ 张开二维复平面 $\to$ 切线垂直速度演化出单位圆 $e^{i\theta}$”**的完整视觉历程。

# Animation Script Specification (三幕无缝衔接动画需求)

1. **第一幕（一维实数轴的局限：乘 $-1$ 转 $180^\circ$）**：
   - 屏幕中央先只画一条水平实数轴（`NumberLine`），在原点 $0$ 到 $1$ 之间绘制一个绿色单位向量 $\vec{v} = 1$。
   - 演示运算 $1 \times (-1) = -1$：绿色向量绕原点逆时针旋转 $180^\circ$（用半圆弧线标注 $180^\circ$），落到 $-1$ 处；再乘一次 $(-1)$，继续逆时针旋转 $180^\circ$ 回到 $1$。
   - 顶部提出问题：**“乘 $-1$ 转 $180^\circ$，那什么数能只转 $90^\circ$？”**

2. **第二幕（乘 $i$ 转 $90^\circ$：虚轴诞生，张开二维复平面）**：
   - 绿色向量重新回到实轴的 $1$ 处。执行运算 $1 \times i$，向量绕原点逆时针精确旋转 $90^\circ$（标注直角符号与 $90^\circ$ 弧线），指向正上方。
   - 此时原本不存在的**垂直虚轴（$\text{Im}$）**从原点向上下动态生长出来（`Create`），一维数轴正式张开为二维复平面，向量顶端落点高亮标记为 **$i$**。
   - 紧接着演示再乘一次 $i$：向量从 $i$ 处继续逆时针旋转 $90^\circ$，精准落回实轴的 $-1$ 处，屏幕浮现核心方程：**$i \times i = -1 \implies i^2 = -1$**。

3. **第三幕（切线垂直速度演化出单位圆：$e^{i\theta} = \cos\theta + i\sin\theta$）**：
   - 清理临时旋转弧线，在复平面上淡入灰色虚线单位圆作为参考轨道，将向量重置回起点 $(1, 0)$ 处。
   - **展现动力学切线速度**：在起点 $(1, 0)$ 处，向上绘制一个亮橙色的切线速度箭头 $\vec{v}_0 = i$（垂直于位置向量）。
   - 使用 `ValueTracker` 让角度 $\theta$ 从 $0$ 平滑增加到 $\pi$（再到 $2\pi$）：
     * 位置向量 $z(\theta) = e^{i\theta}$ 绕原点匀速逆时针旋转，身后留下发光的蓝色圆弧轨迹；
     * 亮橙色速度箭头始终保持与位置向量**垂直**（即 $z'(\theta) = i \cdot e^{i\theta}$），牵引着向量端点的切线方向不断偏转，完美走出单位圆；
     * 右上角同步动态更新公式：$e^{i\theta} = \cos\theta + i\sin\theta$。
   - 当向量旋转到 $\theta = \pi$（落点 $(-1, 0)$）时暂停 1 秒，高亮弹出欧拉恒等式：**$e^{i\pi} + 1 = 0$**，随后完成整圈闭合。
