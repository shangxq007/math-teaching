# Core Content Requirements (核心内容与结构设计)
必须围绕现代数学最核心的解题范式——**“原空间复杂问题 $\xrightarrow{\text{施加变换 } T}$ 新空间标准简单问题 $\xrightarrow{\text{逆变换 } T^{-1}}$ 还原答案”**，系统呈现六大核心降维变换（共轭/不动点变换 + 五大经典变换）：

1. **共轭与不动点变换**（$g = h^{-1} \circ f \circ h$）：
   - **降维魔法**：通过平移原点至不动点 $x^*$（$b_n = a_n - x^*$），消除常数尾巴，将“拉伸+平移”还原为纯粹等比缩放；
   - **微案例**：展示 $a_{n+1} = 2a_n + 3 \xrightarrow{x^*=-3} a_{n+1}+3 = 2(a_n+3)$。
2. **莫比乌斯分式变换**（$f(x) = \frac{ax+b}{cx+d}$）：
   - **降维魔法**：利用双不动点作比 $\frac{a_n - x_1}{a_n - x_2}$ 或重不动点取倒数 $\frac{1}{a_n - x_0}$，将非线性分式递推化为等比/等差数列（揭示其与 $2 \times 2$ 矩阵特征值的同构本质）；
   - **微案例**：展示 $a_{n+1} = \frac{2a_n+3}{a_n+4} \xrightarrow{x_1=1, x_2=-3} \frac{a_{n+1}-1}{a_{n+1}+3} = \frac{1}{5}\frac{a_n-1}{a_n+3}$。
3. **对数变换**（$y = \ln x$）：
   - **降维魔法**：将指数幂次降为线性系数、乘法化为加法，把非线性指数增长曲线拉直为一次直线；
   - **微案例**：指数型递推 $a_{n+1} = 2a_n^3$ 两边取对数秒变线性递推。
4. **仿射变换**（$x' = x, y' = \frac{a}{b}y$）：
   - **降维魔法**：把椭圆均匀拉伸为标准圆，保持共线、平行、中点与面积比例（$S_{\text{圆}} = \frac{a}{b}S_{\text{椭圆}}$）不变；
   - **微案例**：椭圆内接三角形最大面积直接由圆内接正三角形秒算得 $\frac{3\sqrt{3}}{4}ab$。
5. **齐次化与齐次坐标变换**（乘以 $1$ 或平移原点构造 $Ax^2+Bxy+Cy^2=0$）：
   - **降维魔法**：消除非齐次常数项，同除 $x^2$ 将双变量坐标转化为单变量斜率 $k = \frac{y}{x}$ 韦达定理；
   - **微案例**：椭圆过定点弦的斜率之和/积构造齐次二次方程秒解。
6. **欧拉/复数变换与发生函数**（$e^{i\theta} = \cos\theta + i\sin\theta$ 与 $G(x) = \sum a_n x^n$）：
   - **降维魔法**：将三角恒等变换转化为多项式乘法，将无穷数列递推转化为代数方程求系数；
   - **微案例**：用 $e^{i(\alpha+\beta)} = e^{i\alpha}e^{i\beta}$ 两行导出两角和正余弦公式。

提示词模块二：生成“莫比乌斯分式双不动点交叉迭代”Manim 动画脚本

# Role
你是一位精通 Python 与 **Manim Community Edition (manim v0.18+)** 的数学可视化工程师，擅长将非线性分式递推（莫比乌斯变换）的蛛网图迭代转化为流畅、震撼的动态几何动画。

# Task
请为我编写一套完整的 Manim 动画脚本（`MobiusFixedPointScene`），直观演示分式递推数列 $a_{n+1} = \frac{2a_n + 3}{a_n + 4}$ 的**双曲线交叉蛛网图迭代（交错摆动收敛于吸引不动点，同时排斥另一个不动点）**，并同步展示共轭作比公式的诞生。

# Animation Script Specification (分幕动画需求，总时长约 50 秒)

1. **第一幕（绘制分式函数双曲线与寻找双不动点）**：
   - 建立坐标系（$x \in [-4.5, 4.5], y \in [-4.5, 4.5]$），绘制双曲线 $f(x) = \frac{2x + 3}{x + 4}$（在定义域 $x > -4$ 的右支用蓝色光滑曲线绘制，并画出渐近线 $x = -4$ 与 $y = 2$ 的暗灰色虚线）。
   - 绘制参考对角线 $y = x$（浅灰色直线）。
   - 高亮双曲线与直线 $y = x$ 的两个交点，在屏幕上动态写出不动点方程 $x = \frac{2x+3}{x+4} \Rightarrow x^2 + 2x - 3 = 0$，高亮标出两个不动点：
     * **吸引不动点（稳定）**：$P_1(1, 1)$（绿色大圆点，标注 $|f'(1)| = \frac{5}{25} = 0.2 < 1$）；
     * **排斥不动点（不稳定）**：$P_2(-3, -3)$（红色大圆点，标注 $|f'(-3)| = \frac{5}{1} = 5 > 1$）。

2. **第二幕（从排斥点附近出发的蛛网图逃离与螺旋收敛）**：
   - 选取初始值 $a_1 = -2.2$（故意选在排斥不动点 $-3$ 附近，位于双曲线下方）。
   - 执行 **6 步蛛网图迭代（Cobweb Iteration）**：
     * 垂直跳到双曲线 $y = f(a_n)$ $\to$ 水平反射到对角线 $y = x$。
     * 动画将清晰展现：由于 $f'(1) = 0.2 > 0$（注意此处 $f'(x) = \frac{5}{(x+4)^2} > 0$，实际为单调台阶式快速远离 $-3$ 并爬升收敛至 $1$！），点列从 $-2.2 \to -0.78 \to 0.45 \to 0.88 \to 0.98 \to 0.996$，如台阶般迅速逃离红色排斥点 $(-3,-3)$，并精准锁定绿色吸引点 $(1,1)$。
   - **【可选高阶对比增强】**：若想展示交错摆动收敛，可在屏幕角落或第二阶段补充说明导数符号对“单侧台阶收敛（$f'(x^*)>0$）”与“交错螺旋收敛（$f'(x^*)<0$）”的几何决定作用。

3. **第三幕（代数共轭降维公式定格）**：
   - 屏幕右侧弹出总结卡片，同时高亮两个不动点 $x_1 = 1$ 和 $x_2 = -3$，动态浮现莫比乌斯双不动点降维公式：
     $$\frac{a_{n+1} - 1}{a_{n+1} + 3} = \frac{1}{5} \cdot \frac{a_n - 1}{a_n + 3} \implies a_n = \frac{5^n + 3}{5^n - 1}$$
   - 配合底部一句话点睛：“双不动点锁定坐标系两端，非线性分式瞬间坍缩为纯粹等比数列！”
