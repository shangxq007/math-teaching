# Core Pedagogical Logic (核心教学逻辑主线)
必须彻底摒弃高中三角函数“死记硬背几十个零散公式”的痛点，以**“代数指数运算律 $e^{i(\alpha+\beta)} = e^{i\alpha} \cdot e^{i\beta}$ $\leftrightarrow$ 复平面单位圆上的刚体旋转”**为唯一母公理，自然生长出整套三角恒等变换体系：

1. **模块一：建立桥梁 —— 从单位圆点集到复平面指数表示**
   - 将单位圆上的点 $(\cos\theta, \sin\theta)$ 与复平面单位圆周上的复数 $z = \cos\theta + i\sin\theta$ 建立一一对应。
   - 引入欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$，揭示其核心几何公理：**在复平面上，乘以 $e^{i\beta}$ 的几何意义就是将向量逆时针旋转 $\beta$ 角**（模长保持为 1 不变）。

2. **模块二：母公式引擎 —— 一条指数律推导出全套三角恒等变换**
   - **诱导公式的几何秒杀（消除“奇变偶不变”口诀）**：
     * 乘以 $i = e^{i\frac{\pi}{2}}$ 即逆时针旋转 $90^\circ$：通过 $i(\cos\theta + i\sin\theta) = -\sin\theta + i\cos\theta$ 瞬间读出 $\cos(\theta+\frac{\pi}{2}) = -\sin\theta$ 与 $\sin(\theta+\frac{\pi}{2}) = \cos\theta$。
     * 乘以 $-1 = e^{i\pi}$ 即旋转 $180^\circ$，取共轭 $\overline{e^{i\theta}} = e^{-i\theta}$ 即关于实轴对称（奇偶性本质）。
   - **两角和与差的正余弦（多项式乘法一步推导）**：
     * 展开 $e^{i(\alpha+\beta)} = (\cos\alpha + i\sin\alpha)(\cos\beta + i\sin\beta)$，对比实部与虚部，一次性导出 $\cos(\alpha+\beta)$ 与 $\sin(\alpha+\beta)$；将 $\beta$ 替换为 $-\beta$ 立刻得到差角公式。
   - **二倍角与三倍角公式（棣莫弗定理 $(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$）**：
     * 引导学生亲手展开 $(\cos\theta + i\sin\theta)^2$ 和 $(\cos\theta + i\sin\theta)^3$，对比实虚部直接写出二倍角与三倍角公式。
   - **和差化积与积化和差的结构同源性**：
     * 展示 $\cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2}$ 与 $\sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i}$，说明三角函数的和差与乘积本质上就是指数幂的代数恒等变形。

3. **模块三：高观点实战降维与考纲安全边界**
   - **【实战降维】：三角级数/数列求和的机械化秒杀**：演示如何将 $\sum_{k=1}^n \cos(k\theta)$ 转化为等比数列 $\sum_{k=1}^n (e^{i\theta})^k$ 求和后取实部，彻底摆脱繁琐的辅助角裂项技巧。
   - **【考纲落地防火墙】**：明确提醒学生——高考解答题默认在实数域 $\mathbb{R}$ 评分，复数法用于**选填小题秒杀、快速验算及忘记公式时的现场推导**，解答题书写仍需还原为实数三角变换格式。

4. **模块四：分层随堂与课后巩固（6道精选例题与练习）**
   - 包含：利用欧拉公式现场推导三倍角公式、利用旋转几何意义秒判复杂诱导公式、复数等比数列秒杀三角求和 $\cos x + \cos 2x + \dots + \cos nx$、以及实数域还原规范书写对照练习。每题均附带【复平面结构剖析】+【标准解答】+【实战边界提示】。

# Animation Scenes Specification (分场景动画需求)

## Scene 1: `EulerRotationSumFormula`（复平面单位圆旋转与两角和公式投影诞生）
请设计一个约 50 秒的流畅动画，采用**左图（复平面单位圆）+ 右栏（代数推导同步浮现）**的左右分屏布局：
1. **第一幕（建立复平面单位圆与初始向量 $z_1 = e^{i\alpha}$）**：
   - 左侧绘制复平面（实轴 $\text{Re}$ 与虚轴 $\text{Im}$）及蓝色单位圆。
   - 绘制从原点出发、辐角为 $\alpha = 30^\circ$ 的绿色单位向量 $z_1 = e^{i\alpha}$，同步画出其向实轴和虚轴的虚线投影，标注坐标 $(\cos\alpha, \sin\alpha)$。
2. **第二幕（乘以 $e^{i\beta}$ 的几何意义：逆时针旋转 $\beta$ 角）**：
   - 顶部/右侧显示运算指令：$z_1 \cdot e^{i\beta} = e^{i\alpha} \cdot e^{i\beta} = e^{i(\alpha+\beta)}$。
   - 动画演示绿色向量 $z_1$ 绕原点逆时针平滑旋转 $\beta = 40^\circ$（用黄色扇形弧线标出旋转角 $\beta$），到达新位置形成橙色向量 $z_2 = e^{i(\alpha+\beta)}$（总辐角为 $\alpha+\beta$）。
3. **第三幕（几何投影与代数展开的同源对照）**：
   - 从橙色向量端点向实轴和虚轴作垂线，高亮其横坐标 $\cos(\alpha+\beta)$（红色线段）与纵坐标 $\sin(\alpha+\beta)$（青色线段）。
   - 右侧代数栏同步动态展开多项式乘法：
     $$(\cos\alpha + i\sin\alpha)(\cos\beta + i\sin\beta) = (\cos\alpha\cos\beta - \sin\alpha\sin\beta) + i(\sin\alpha\cos\beta + \cos\alpha\sin\beta)$$
   - 用相同颜色高亮实部与虚部，与左侧几何投影线段建立连线/闪烁呼应，定格展示两角和的正余弦公式。

## Scene 2: `MultiplyByIInduction`（乘以虚数单位 $i$ 秒杀诱导公式）
请设计一个约 30 秒的精炼动画：
1. 在复平面单位圆上绘制任意第一象限单位向量 $z = \cos\theta + i\sin\theta$（标注横坐标 $\cos\theta$ 为蓝色，纵坐标 $\sin\theta$ 为绿色）。
2. 执行乘法 $i \cdot z = e^{i\frac{\pi}{2}} \cdot e^{i\theta}$，动画演示向量绕原点逆时针精确旋转 $90^\circ$（标出直角符号）。
3. 旋转完成后，直观展示原本竖直方向的绿色线段 $\sin\theta$ 倒向了实轴负半轴，变成 $-\sin\theta$；原本水平方向的蓝色线段 $\cos\theta$ 竖立到了虚轴正半轴，变成 $\cos\theta$，瞬间得出：
   $$\cos\left(\theta + \frac{\pi}{2}\right) = -\sin\theta, \quad \sin\left(\theta + \frac{\pi}{2}\right) = \cos\theta$$
