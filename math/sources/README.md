## 使用约定

- 素材里的 `FONT_NAME = "SimHei"` 是给别的机器写的；**本机必须用 `"Noto Sans Mono CJK SC"`**
  （见 `../manim/README.md`）。素材里的 `\{`/`\}` 转义在 Markdown 里也是多余的。
- 素材中的 Manim 代码只作参考，布局尺寸要按本机 16:9 画幅重算（坐标轴 ≤ 6.6，见 `../manim/README.md`）。
- 素材里的 LaTeX 片段（如 `\begin{remark}`）不一定在本项目模板里存在；落笔时映射到
  `../common/macros.tex` 与 `../common/envs.tex` 里的现有环境。
