## 1. 第 2 章（三角与复平面旋转）

### S1 `EulerRotationSumFormula`（scene1_euler_rotation.py）
- 视频内容：单位圆上 `z1=e^{iα}`（α=30°）向两轴作虚线投影标 `(cosα,sinα)` → 乘 `e^{iβ}`（β=40°）逆时针转到 `z2=e^{i(α+β)}`，黄色扇形弧标 β → 从 z2 端点作垂线，红=cos(α+β)、青=sin(α+β)；右栏展开 `(cosα+isinα)(cosβ+isinβ)` 并分「实部/虚部」定格两角和公式；字幕「一次复数乘法 = 旋转 + 投影」。
- 与教案重合：两角和公式的展开与对比实虚部（02.tex L258–271）完全一致；母公理「乘 e^{iβ}=逆时针转 β」（L8–11）。
- 视频独有：复平面上 α→α+β 的动态旋转 + 双色投影 + 具体角 30°/40°；教案此节为纯代数推导，无图。
- 教案独有：差角公式（L272–276）、后续三倍角/和差化积等。
- **缺口**：02.tex 现有两图（fig:rotate-i 讲 ±1/i 的 180°/90°，fig:euler-tangent 讲切线速度）都不覆盖「任意 α 加转 β 得 α+β」的旋转叠加图。建议补 1 张 TikZ：左 z1 与投影、右 z2=e^{i(α+β)} 与两轴投影，颜色沿用红=实部、青=虚部。

### S2 `MultiplyByIInduction`（scene2_multiply_by_i.py）
- 视频内容：θ=36°，蓝线段=cosθ、绿线段=sinθ → 乘 i=e^{iπ/2} 转 90°（直角符号 + 90° 弧）→ 绿线倒向负实轴成 −sinθ、蓝线竖到正虚轴成 cosθ → 定格 `cos(θ+π/2)=−sinθ`、`sin(θ+π/2)=cosθ`。
- 与教案重合：诱导公式本体（02.tex L244–252）逐字一致。
- 视频独有：「cos/sin 线段整体倒置」的动态几何；蓝/绿与实/虚的固定配色。
- 教案独有：乘 −1、共轭与奇偶性（L253–256）、「奇变偶不变，符号看象限」口诀化解释。
- **缺口**：fig:rotate-i 有「乘 i 转 90°、i²=−1」，但没有任意 θ 下「分量倒置读数」的图。建议补 1 张 TikZ：同一单位圆并排画转前（cosθ,sinθ）与转后（−sinθ,cosθ）两组直角边。

### S3 `ImaginaryAndEulerGenesis`（scene3_imaginary_genesis.py）
- 视频内容：一维数轴上 1 乘 −1 逆时针转 180°（半圆弧）→ 再乘回 1 → 提问「什么数能只转 90°」→ 乘 i 转 90°、虚轴生长、落点 i、i×i=−1 → 淡入虚线单位圆，橙色切线速度箭头始终垂直，θ 从 0 到 2π 匀速留轨迹；右上 `e^{iθ}=cosθ+isinθ`，θ=π 处弹 `e^{iπ}+1=0`。
- 与教案重合（几乎逐条）：探究一「乘 −1 转 180° / 乘 i 转 90° / i²=−1 / 虚轴生长」（L54–67 + fig:rotate-i L69–97）；探究三切线速度 z′(0)=i、锁定 k=i、欧拉公式与 e^{iπ}+1=0（L172–196 + fig:euler-tangent L212–232）。这是三场景中与教案重叠度最高的一个。
- 视频独有：一维数轴起手的提问式叙事；θ 连续旋转 + 轨迹 + 速度箭头动态；θ=π 暂停弹出恒等式。
- 教案独有：数系扩张表 N→Z→Q→R→C（L123–137）、卡丹公式例 `(2+i)³=2+11i`（L102–121）、「连喊两次向左转」点睛（L99–100）。
- **缺口**：基本无。若要做锦上添花，可把「速度箭头始终垂直」做成 fig:euler-tangent 的注解图；但该图已含 z′(0)=i 与 i·z(θ) 垂直标注，优先级最低。

### 第 2 章小结
- 实质缺口仅 2 张图（两角和旋转叠加图、乘 i 分量倒置图）。
- 反向差异（教案有、视频无）：结构同构证明（L144–170）、二倍角三倍角与棣莫弗（L278–293）、和差化积/积化和差（L295–309）、等比数列求和（L323–339）、考纲边界 conccard（L341–346）、解三角形整节（L363–444）。属「视频选讲、教案全载」的定位差，非缺陷。

## 2. 第 3 章（平面向量与空间向量）

### V-S1 `BasisDecomposition`（scene1_basis.py）
- 视频内容：斜交基底 e1=(1,0.32)、e2=(−0.32,1) → 任取 a，x=1.5、y=0.95 → 从端点作两条与基底平行的虚线「拉开」成平行四边形（填充）→ 高亮 x·e1、y·e2 → 定格 a=x e1+y e2 与「基底选得巧，计算就少」。
- 与教案重合：平面向量基本定理、存在性（平行四边形）、唯一性、斜交基底不要求垂直、「选得巧计算就少」（03.tex L62–79、L135）。
- 数值差异：视频 e1/e2 取近似正交的对称斜基、系数 1.5/0.95；教案 fig:basis-coord 左图取 E1=(2,0.5)、E2=(0.6,1.6)，即 a=2e1+1e2（L100–112）。几何同构，读数不同。
- 视频独有：平行四边形动态拉开 + 分量箭头依次生长。
- 教案独有：正交单位基底与坐标（右图）、中点公式例（L138–151）、三点共线等和线（L155）、唯一性反证（L71–76）、坐标运算规则（L89–94）。
- **缺口**：无。fig:basis-coord 左图即视频内容的静态版。

### V-S2 `DotProductProjection`（scene2_dot_projection.py）
- 视频内容：b 方向 18°、|b|=1.6；a 长 1.7、角度 75°→108°→148° 连续变化，从 a 端点向 b 所在直线作垂线，红色投影段同步收缩→零→反向；定格 a·b=|a||b|cosθ 与 `proj_b a=(a·b/|b|²)b`；字幕「投影是带符号的：θ 为钝角时 cosθ<0」。
- 与教案重合：定义、投影向量公式、数量投影、垂足 H、fig:dot-proj 的锐角 θ=40° 图示（L192–216）；钝角为负在例题（|a|=4,|b|=5,θ=120°，L230–239）与 commonerror 失误三（L255–257）出现。
- 视频独有：θ 扫过直角/钝角时投影方向翻转的动画与「锐角/直角/钝角」状态字。
- 教案独有：坐标运算推导（L170–182）、夹角公式、与余弦定理互译（L218–228）、三个高频失误（L247–258）。
- **缺口**：fig:dot-proj 只画锐角一态；钝角/直角只有文字与例题，无图。建议补 1 张三态并排（或双联）TikZ：θ<90° 投影同向、θ=90° 缩为零、θ>90° 投影反向。

### V-S3 `NormalVectorDihedral`（scene3_normal_vector.py）
- 视频内容：沿棱 l 的 head-on 投影图（棱用圆圈+圆心点表示），两半平面 α、β 扇形张开，二面角 θ → 各面内法向量 n1⊥α、n2⊥β，标法向量夹角 φ；θ=120°→90°→60° 动态，φ 同步；同侧 φ=180°−θ、异侧 φ=θ；定格「相等还是互补：看图判定锐钝」+ 平行/垂直/夹角三条判据。
- 与教案重合：二面角公式 `|cosθ|=|n1·n2|/(|n1||n2|)`、「锐钝结合图形判断」、判据表（03.tex L359–388、conccard L457–462）。
- 视频独有：二面角的**几何图**（两个半平面 + 棱 + 两个法向量 + 平面角 φ）与「φ 与 θ 相等或互补」的动态论证。
- 教案独有：空间坐标化、线面角 sinφ 公式与 fig:space-normal（L390–420）、正方体二面角例题（L422–441）、建系三失误（L464–474）。
- **缺口（第 3 章最大）**：03.tex 无任何二面角几何图，fig:space-normal 只讲线面角；而二面角平面角与「法向量夹角相等或互补」正是本课难点。建议补 1 张 TikZ：沿棱投影的二面角图，并排画「同侧 φ=180°−θ」与「异侧 φ=θ」两态。

### V-S4 `ChangeBasisSimilarity`（change_basis_similarity.py）—— 教案无对应
- 视频内容：标准基下 A=[[2,1],[0,1]]、v=(2,1)→T(v)=(5,1)；换新基 u1=(1,1)、u2=(−1,1)（P=[[1,−1],[1,1]]）→ [v]_B′=(3/2,−1/2)、[T(v)]_B′=(3,−2) → 定格 `A′=P⁻¹AP=[[2,0],[−1,1]]`，字幕「换基底只是换读数，变换本身纹丝不动」。
- 教案现状：03.tex 仅在课后基础 2 用 e1′=e1+e2、e2′=e1−e2 求坐标 (3/2,−1/2)（L511、L536–548）——读数巧合相同，但**没有线性变换、矩阵、相似互换律**。
- **缺口/决策点**：属超纲内容（矩阵相似）。建议不在正文补，可在章末「拓展阅读」或教师版加一段说明性链接，或明确标注为视频专属拓展。

### V-S5 `VectorMirrorReflection`（vector_mirror_reflection.py）—— 教案无对应
- 视频内容：以 b=(3,1) 所在直线为镜面，a=(2.5,1.5)；先投影得 proj_b a=(2.7,0.9)（垂足为 aa′ 中点）→ 反射像 a′=(2.9,0.3)；定格 `a′=2 proj_b a − a` 与「镜面是 a 与 a′ 连线的垂直平分线」。
- 教案现状：只有 proj_b a 的定义与公式（L184–190），无反射应用。
- **缺口/决策点**：可作为「数量积与投影的应用」补 1 道例题 + 1 张小图（成本低、与正文衔接顺）；也可归入培优/拓展。

## 4. 其他全局观察

- **色彩语义**：视频固定蓝=cos/绿=sin/红=实部/青=虚部/黄=强调/橙=第二对象；教案 TikZ 用 main/second/third 色系但未绑定对象语义。若要一一对应视频，可在 02/03 图注中显式声明颜色含义。
- **数值 vs 抽象**：视频用 30°/40°/36°/1.5/0.95 等具体值降低门槛；教案坚持抽象记号 + 反例 + 考纲边界（如 02.tex L341–346、03.tex L247–258）。两者是互补而非冲突。
- **媒体核对**：8 个场景脚本均存在且已渲染（media/videos 下有对应 mp4）；hv-guide 第 2、3 章均为原生 TikZ，无外部图片，符合工程约束。
