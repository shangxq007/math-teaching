# hv-guide 章内结构与次序审计

- 范围：`chapters/00.tex`–`chapters/07.tex`、`chapters/08_homogenization.tex`；另附 `demo_multiversion.tex` 与两个附录，用于核对多版本设计。
- 方法：只读扫描 `main_body.tex` 实际挂载顺序下的 `\section` / `\subsection*` / `\paragraph`，并定位 `advancedonly`、`basiconly`、`solution`、`conccard`、`notezone` 的起止行。未修改任何源文件。
- 结论先行：
  1. **无真正的重复小节**。唯一同名的是第 8 章 `第 3 节`（advancedonly 版 vs basiconly 版），属于条件编译的设计性分流，不是源码冗余。
  2. **没有发现主体被 advancedonly 挤成次要的证据**：第 0–7 章正文不含 `advancedonly`；只有第 8 章和示范章使用。但第 8 章的「第 3 节」高观点版确实占据该节全部正式内容，需按设计意图评估。
  3. **存在局部次序风险**：第 8 章的当堂检测、分层作业、母题解答均把 `solution` 紧跟在题目之后；第 5 章教师版答案后又出现一道问题及其解答；第 8 章末尾 advancedonly 评注没有对应的基础/主标题。
  4. **notezone 明显失衡**：全册仅第 8 章有 2 个 `notezone`，第 0–7 章、附录均为 0；conccard 数量则从 3（第 8 章）到 7（第 5 章）不等。

## 2. 四项检查

### (1) 同名小节

- 第 8 章第 149 行与第 184 行都写成 **`第 3 节`**，但分别包在互斥的 `advancedonly` 与 `basiconly` 中；在任何单一编译版本里最多出现一个，因此属于**设计性同名**（同一节的完整版/薄弱生版），不是普通重名错误。
- 示范章用 `第 (4) 问` / `第 (4)' 问` 区分，也属于设计性分流。
- 其余各章 subsection 标题无重复；「知识回顾」「教材速读」「基础巩固」「进阶提升」「拓展探究」「教师版答案」是跨章固定骨架标题，不属于章内同名冲突。

### (2) advancedonly 是否挤压主体

- 第 0–7 章**完全没有** `advancedonly`/`basiconly`；其高观点内容直接作为正文主体，不存在版本块挤压主线的现象。
- 第 8 章 `advancedonly` 仅覆盖第 148–181 行，内部只有第 3 节完整推导和一个 example；紧接着的 basiconly 是第 183–193 行。二者体量接近，且后面第 4 节仍有大量通用正文，**未观察到主体被高观点版挤成次要的硬证据**。
- 需要留意的是：第 8 章的「第 3 节」完整版几乎全是高观点内容（射影/矩阵），而 basiconly 版只是半页大白话；这是设计取舍，但若以“主体内容”应服务大多数学生为口径，该节的完整功能确实由 advancedonly 承担，基础版只保留入口直觉。
- 第 8 章 420–428 的 advancedonly 是对已给出解答的母题再做评注，没有配套 basiconly，导致薄弱生版在此处直接跳过该段；属于设计允许的差异，但位置在“答案之后、总结卡之前”，削弱了它作为正文延伸的作用。

### (3) 习题与答案次序

- 常规章（0–7）骨架一致：`基础巩固 → 进阶提升 → 拓展探究 → 教师版答案`，且教师版答案统一位于三类习题之后；**未见 solution 整体出现在习题之前**。
- 第 8 章存在若干“题目后立即给答案”的局部写法，但不构成教师版答案区错位：
  - 197–238：5 道 problem 各自紧跟 solution；
  - 240–250：inclasstest 内嵌 solution；
  - 252–266：homework 内嵌 solution；
  - 295–405：两道 masterq 各自紧跟 solution。
  这些是“即练即析”的编排选择；若期望学生先独立作答，属于版面次序风险，而不是答案区整体倒置。
- 明确的结构异常：**第 5 章 719 行在教师版答案区结束后又新开 `\subsection{跨章方法论…}`，其中 744–759 仍是 problem+solution**。这会把课后题/答案区之后又拉回一节正文与题解，破坏“习题→教师版答案”收尾的稳定性，建议列为首要修复对象。
- 第 8 章没有独立的 `基础巩固/进阶提升/拓展探究/教师版答案` 骨架，而是把 problem/solution/inclasstest/homework/masterq 混排在节内；因此无法按其他章的“答案区”规则判断，只能提示读者注意答案紧邻题目的设计。

## 4. 版本开关影响（只读确认）

- `versions.tex` 中 `advancedonly` 仅在 `\ifbasic` 为假时输出；`basiconly` 仅在 `\ifbasic` 为真时输出。故同名第 3 节在四种版本中每次只渲染一种。

- `main.tex` 默认 `\teachertrue\basicfalse`；`\demomodefalse`，故当前默认成品不含示范章。
