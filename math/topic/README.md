# 数学专题训练

用 ElegantNote 模板写的专题训练，供学生跨课次综合运用。

与另外几个文档的区别：

| 文档 | 组织方式 | 读者 |
| --- | --- | --- |
| 导学案 | 按课时 | 学生（课前 / 课中） |
| 专题训练 | 按主题 | 学生（课后综合） |

## 结构

- `main.tex` — 封面与目录
- `chapters/` — 每个专题一个文件，文件名以两位序号开头（`01.tex`、`02.tex`）

新增专题：在 `chapters/` 加文件，在 `main.tex` 里加一行 `\input{chapters/02}`。

## 写法约定

- 单位是**专题**（跨课次的主题），不是课次；
- 每个专题 = 一组「种子问题」+ 若干「视角」；
- 视角按知识积累排列；常见视角：来源、证明、函数、运算、极值、几何（按主题选用）；
- 同一道种子问题在不同视角下反复出现，每次换一种解法（这是「螺旋式」的关键，用「回头看」标出）；
- 每个视角：要点 + 例题 + 练习；专题末：变式训练 + 知识来源对照表；
- 超前内容（线性规划、导数）与课内内容同等对待，不单独标注。

## 编译
