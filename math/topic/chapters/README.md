# 专题训练章节目录

每个文件对应一个专题，文件名以两位序号开头，按顺序在 `../main.tex` 中 `\input`。

- `01.tex` — 集合与命题
- `02.tex` — 不等式
- `03.tex` — 函数与方程
- `04.tex` — 极值与最值
- `05.tex` — 恒成立与能成立
- `06.tex` — 凸性、差分与整数最值
- `07.tex` — 内积与柯西不等式
- `08.tex` — 指数与对数
- `09.tex` — 三角函数的图象与性质
- `10.tex` — 抽象函数与函数符号
- `11.tex` — 整体代换（换元）
- `12.tex` — 存在与任意：否定、解集结构与存在性

新增专题步骤：

1. 在此目录新建 `NN.tex`（如 `11.tex`）；
2. 在 `../main.tex` 中追加 `\input{chapters/11}`；
3. 保存即自动编译。

模板使用 ElegantNote（article 结构），章节用 `\section`。每个专题 = 种子问题 + 若干视角
+ 变式训练 + 知识来源对照表；回指种子问题时标「回头看：种子问题 N」。
