# 建模活动单章节目录

每个文件对应一组建模活动，文件名以两位序号开头，按顺序在 `../main.tex` 中 `\input`。

- `01.tex` — 三个活动：人口增长（指数模型）、声音强度（对数模型）、行星轨道（幂模型）
- `02.tex` — 活动四、五：纸带拟合与自由落体测楼高（二次模型）
- `03.tex` — 活动六、七：茶杯降温与碳-14 测年（指数衰减）
- `04.tex` — 活动八、九：潮汐与摩天轮、音叉拍频（三角模型）
- `05.tex` — 活动十、十一：椭圆轨迹与 Dandelin 球（几何建模）
- `06.tex` — 活动十二、十三：长方体与圆柱最优包装（基本不等式）
- `07.tex` — 活动十四、十五：定价利润最大与两段门票（二次函数最值）
- `08.tex` — 活动十六、十七：逻辑斯蒂人口与干预时机（S 形增长）
- `09.tex` — 活动十八、十九：抽奖期望与猜题策略（离散概率）
- `10.tex` — 活动二十、二十一：最小二乘回归与 Anscombe 陷阱（统计建模）

## 说明

建模活动单与专题训练不同：专题训练是「同一问题换工具」，建模是「同一现象换模型」，
所以单独成册，走完整的建模过程（提出问题 → 选模型 → 拟合 → 检验 → 预测 → 报告）。

新增活动：在此目录新建 `NN.tex`，并在 `../main.tex` 中 `\input`。
