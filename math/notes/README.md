# 笔记

学生课上记、课后补的笔记本。

## 定位与分工

| 文档 | 性质 | 空里写什么 |
| --- | --- | --- |
| 导学案 `../guide/` | 任务单 | 有标准答案的填空与探究 |
| **笔记（本目录）** | **记录本** | **由学生自己决定** |
| 错题本 `../errorbook/` | 订正本 | 错因、正解、变式、反思 |

核心区别：**留白处没有标准答案**。所以不要印「请填空」这种指令，
要印「我当时卡在哪一步」这种提示。

## 结构

每个课题四个区，顺序固定：

1. `notezone{课前：我已知什么}`——激活旧知
2. `notezone{课中：概念怎么说的}`——抄要点
3. `notezone{课中：一道我没听懂的例题}`——定位卡点
4. `notezone{课后：我能复述什么}`——输出倒逼输入

留白用 `\noteblank[长度]`，默认 6ex，按需给 8ex～18ex。

## 编译

```bash
cd notes
latexmk -xelatex -g main
```
