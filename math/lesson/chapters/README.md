# 教案章节目录

每个文件对应**一章**（内容完整，课时划分由教师把握）。文件名以两位序号开头，
按顺序在 `../main.tex` 中 `\input`。

- `01.tex` — 集合与常用逻辑用语（湘教版第 1 章）
- `02.tex` — 一元二次函数、方程和不等式（湘教版第 2 章）
- `03.tex` — 函数、幂函数、指数函数、对数函数（湘教版第 3、4 章）
- `04.tex` — 三角函数（湘教版第 5 章）

新增章节步骤：

1. 在此目录新建 `NN.tex`（如 `05.tex`）；
2. 在 `../main.tex` 的 `\mainmatter` 之后追加一行 `\input{chapters/05}`；
3. 保存即自动编译。

模板使用 ElegantBook，章节用 `\chapter`；章内的内容分节用 `\section`（放在
`procedure` 环境内），章首在 `keypoint` 里给出课时建议。
