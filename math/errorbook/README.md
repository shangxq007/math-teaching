# 错题本

学生订正用。一题一条，四段固定：**错解 → 正解 → 变式 → 反思**。

## 定位与分工

| 文档 | 内容 |
| --- | --- |
| 笔记 `../notes/` | 今天学了什么 |
| **错题本（本目录）** | **我错在哪、为什么、怎么不再错** |
| 题库 `../bank/` | 题源（错题从这里挑） |

## 结构

每条用 `mistake` 环境，可选参数是**错因分类**：

```latex
\begin{mistake}[概念不清]
（原题）...

\wrong{错解}
\correct{正解}
\variant{变式}
\reflect{反思}
\end{mistake}
```

错因分类固定用这几类：`概念不清`、`运算错误`、`审题不细`、`方法不当`、`时间不够`、`书写不规范`。
分类的作用是期末统计——哪一类错得多，就补哪一类。

## 三条原则

- **错解必须抄自己写的**，不要抄正确答案的逆过程；
- **反思写「下次怎么识别」**，不写「我要认真」；
- **变式必须自己编或从 `../bank/` 挑一道**，不能留空。
